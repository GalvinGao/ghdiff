# reviewer

A code review surface built on [`@pierre/diffs`](https://diffs.com) and
`@pierre/trees`.

Reviewer renders a diff from a GitHub URL or from a local git repository, shows
the changed files in a file tree, and lets you leave line comments. Comments on
a GitHub pull request sync to that pull request through the GitHub API.
